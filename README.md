# ioBroker auf QNAP TS-1273AU

Dieses Repository verwaltet die Docker-Compose-Konfiguration für ioBroker auf der QNAP Container Station.

**Architektur:** ioBroker läuft auf dem QNAP. Der Homematic-Raspberry-Pi bleibt für die lokale Haussteuerung eigenständig.

Die eigentliche Einrichtung wird über einen separaten Arbeitsbranch vorbereitet und erst nach Prüfung nach `main` übernommen.
